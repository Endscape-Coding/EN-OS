# Как собрать кастомную систему?

> [!TIP]
> Язык: 🇷🇺 **Русский** | 🇺🇸 [English](Make_iso_en.md)

#### Перед началом:
- **Рекомендуемая система:** Arch Linux или производные (Manjaro, EndeavourOS и т.д.)
- **На Debian, NixOS и других дистрибутивах:** Сборка может завершиться ошибкой или дать некорректный результат
- **Требования к диску:** Минимум 15 ГБ свободного места
- **Интернет-соединение:** Рекомендуется стабильное высокоскоростное подключение
- **Требования к системе:** Многоядерный процессор, 8+ ГБ ОЗУ для оптимальной производительности
- **Примерное время сборки:** 30-90 минут в зависимости от системы и скорости интернета

#### Приступим!

**Шаг 1: Установите необходимые пакеты**
```bash
# На системах на базе Arch:
sudo pacman -S archiso git

# Опционально, но рекомендуется для ускорения сборки:
sudo pacman -S pigz zstd  # Инструменты параллельного сжатия
```

**Шаг 2: Клонируйте репозиторий**
```bash
git clone https://github.com/Endscape-Coding/EN-OS.git
cd EN-OS
```

**Шаг 3: Перейдите в нужную редакцию**
```bash
# Выберите интерфейс и редакцию:
cd build-profiles/EN-OS-KDE-Standard/       # KDE Стандартная
# ИЛИ
cd build-profiles/EN-OS-KDE-Gaming/         # KDE Игровая
# ИЛИ
cd build-profiles/EN-OS-XFCE-Standard/      # XFCE редакция (Бета)
```

**Шаг 4: Настройте под себя (опционально)**
Отредактируйте файлы конфигурации по своему усмотрению:
- `packages.x86_64` – Список пакетов
- `airootfs/` – Модификации корневой файловой системы
- `profiledef.sh` – Настройки профиля сборки
- `pacman.conf` – Конфигурация менеджера пакетов

> 💡 **Совет:** Используйте встроенный скрипт `customize_airootfs.sh` для автоматизации пост-установки.

**Шаг 5: Соберите ISO-образ**
```bash
# Базовая сборка (результат в work/out/ текущей директории)
sudo mkarchiso -v .

# Пользовательская выходная директория (рекомендуется для SSD)
sudo mkarchiso -v -o /путь/к/директории .

# Продвинутый вариант: Чистая сборка с параллельным сжатием
sudo rm -rf work/ 2>/dev/null || true
sudo mkarchiso -v -w work -o /путь/для/вывода .
```

**Шаг 6: Проверка и тестирование**
```bash
# Проверка целостности ISO
sha256sum EN-OS-*.iso

# Опционально: Тестирование в QEMU (установите qemu сначала)
sudo pacman -S qemu-base
qemu-system-x86_64 -cdrom EN-OS-*.iso -m 4G -enable-kvm
```

#### Дополнительные опции:
- **Минимальная сборка** (быстрее, но ISO больше):
  ```bash
  sudo mkarchiso -v -r .
  ```
- **Пропустить проверку** (только для тестирования):
  ```bash
  sudo mkarchiso -v -s .
  ```

#### Где мой ISO?
- По умолчанию: `work/out/` внутри вашей директории сборки
- Пользовательская директория: Путь, указанный с флагом `-o`
- Имя файла: `EN-OS-<редакция>-<дата>-x86_64.iso`

#### Что дальше?
1. **Протестируйте** ISO в виртуальной машине (VirtualBox, VMware, QEMU)
2. **Запишите** на USB: `sudo dd if=EN-OS.iso of=/dev/sdX bs=4M status=progress`
3. **Сообщите об ошибках** на [странице Issues GitHub](https://github.com/Endscape-Coding/EN-OS/issues)
4. **Предложите улучшения** через Pull Requests

#### Решение проблем:
- **Сборка не удалась:** Проверьте подключение к интернету и свободное место
- **Отсутствуют пакеты:** Убедитесь, что `archiso` обновлен
- **Ошибки прав доступа:** Запустите с `sudo` и проверьте права пользователя
- **Медленная загрузка:** Отредактируйте `pacman.conf` для использования быстрых зеркал

> 📚 **Подробнее об опциях archiso** в [официальной документации Arch Linux](https://wiki.archlinux.org/title/Archiso).
